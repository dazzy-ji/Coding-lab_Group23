# Coding-lab_Group23

## Project Overview
This project is a mini hospital monitoring and management system developed collaboratively using Git and GitHub workflows.

The project includes:
- Python system logic
- Bash automation scripts
- Linux permission management
- Data archiving
- Reporting and analysis



## Repository Structure

### hospital_system.py
Core hospital system logic powering the hospital application.

### hospital_admin.sh
Handles milestones M1, M2, and M3 including:
- environment setup
- service setup
- permission management

### hospital_archive.sh
Handles milestone M4 data archiving operations.

### hospital_analysis.sh
Handles milestones M5 and M6 including:
- reporting
- analytics
- log analysis

### .gitignore
Excludes logs and generated reports from version control.

## How to Run

Run the Bash script:

```bash
./hospital_admin.sh
```

Check permissions:

```bash
ls -ld active_logs
```



## Git Workflow

Each team member worked on a separate branch and used:
- git add
- git commit
- git push

before merging contributions into the main branch.
